# Constitution

**The constitution lives at [`.specify/memory/constitution.md`](../.specify/memory/constitution.md).**

That is the authoritative location, because the Spec Kit tooling reads it from there
(`idea.md` §58). This file is a pointer only.

**There must never be two copies.** A duplicated constitution drifts, and drifted
engineering law is worse than none — an agent may load the stale copy and cite it with
confidence. See ADR-016 for the same reasoning applied to skills.
